# Omnifood Website

Welcome to the Omnifood project! This is a simple, responsive food delivery website that provides users with a modern, intuitive interface to browse and order meals. The footer section is one of the key components of the website, providing navigation, contact details, and social media links.

## Preview

You can see the DEMO <a href="https://omnifood-altamash.vercel.app/" target="_blank">HERE</a>.

## Features

- **Responsive Layout**: The footer adapts to various screen sizes to ensure it looks good on desktop, tablet, and mobile devices.
- **Contact Information**: Provides the address, phone number, and email contact for the company.
- **Dynamic Copyright Year**: The copyright year in the footer updates automatically based on the current year.
- **Quick Links**: Links to important sections of the website such as account creation, company information, and resources.

## Key Skills Used in the Project

- **HTML5**  
  Structured the website using semantic and accessible markup to create well-organized, SEO-friendly pages.

- **CSS3**  
  Designed responsive layouts using Flexbox and Grid, added visual hierarchy with modern typography and color schemes, and implemented subtle animations for user engagement.

- **JavaScript (Vanilla JS)**  
  Added small-scale dynamic interactions, including the auto-updating footer year, and enhanced user navigation experience.

Together, these skills highlight a strong grasp of **front-end development**, **responsive design principles**, and **attention to visual detail**.

## Installation & Setup

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Altamash-khn/Omnifood.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Omnifood
   ```
3. Open `index.html` in your preferred browser or use **Live Server** in VS Code for real-time preview.
